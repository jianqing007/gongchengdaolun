# v0.5 版本说明

- 日期：2026-11-04
- 状态：在 v0.4 之上做体验层升级（界面动效、日K历史回放、信号卡存图）；数据链路、指标口径、告警规则均未改动
- 运行：双击 `start.bat`，或 `python -m http.server 8000` 后打开 `index.html`
- 自检：`tests.html` 110 / 110 通过（v0.5 改动全部在 UI 层，未新增/修改纯函数用例）
- 数据：与 v0.4 相同（26 个标的，快照截至 2026-10-30）

## 一句话目标

从"能用"到"好看好用"：给页面加上行情软件的呼吸感（数字滚动、涨跌闪烁、图表入场动效），并把快照历史变成可回放的"录像"（日K回放），同时给报告演示配一个一键产出物（信号卡存图）。

## 为什么这样改

- 课程要求强调创新点，v0.4 的创新集中在数据链路与规则引擎（配置化清单、增量快照、250 根 MACD、指数闸门、walk-forward 回测），界面层表达不足；
- 3 秒刷新的数字是"跳变"的，变化发生在哪一眼看不出来，涨跌闪烁能直接指认；
- 快照里有 2015 年至今约 2800 根日线，但只能静态地看，回放能展示"指标随时间演化"的过程，适合答辩演示；
- 演示和报告需要固定素材，逐张截图不如一键把信号卡导出成图片。

## 本次实现

### 1. 数字滚动与涨跌闪烁（A1）

- 新增 `js/ui/motion.js`：`Motion.setNum`（requestAnimationFrame 数字补间，easeOutCubic 420ms）与 `Motion.flash`（闪红/闪绿后 animationend 自动移除类）；
- 接入四处：指数卡（价格/涨跌幅/涨跌额）、自选表（价格/涨跌幅/涨跌额）、持仓表（现价/市值/浮动盈亏/盈亏比例/日盈亏）、汇总卡（总市值/总成本/浮动盈亏/今日盈亏）与图表摘要价格；
- 值不变不闪、值为空回落 `--`；连续刷新会打断上一轮补间，从当前显示值续滚。

### 2. 图表入场动效（A2）

- `kline-chart.js`：`draw` 拆为入口 + `drawImpl`，payload 带 `animate` 时用 rAF 驱动 progress 0→1（640ms）；K 线/成交量/MACD 柱按位置错峰从基线生长，均线/BOLL/副图线只画到 `lineEnd`，十字光标在动画结束后才显示；
- `minute-chart.js`：同结构，分时线与面积用 clip 从左向右描出（700ms）；
- 只有切换标的/周期/首次加载时触发（`state.chartIntro` 门控），3 秒例行刷新与窗口缩放不重播；任何一次普通绘制都会使动画令牌失效，立即回到完整帧。

### 3. 日K历史回放（A3）

- 图表面板新增回放条：回放/暂停/继续/重播、1×–8× 变速（1× = 每根 200ms）、进度条、当前日期、退出；
- 回放范围从第 2 根到最新一根；画布始终显示"截至当前回放位置"的完整历史（range=0），坐标轴随数据范围自适应；
- **指标按"当日为止"重算**：每前进一根，对切片重新调用 `buildKlineSeries`，MA/MACD/KDJ/RSI/BOLL 都是当时真实可见的值，不用未来数据；样本不足时如实显示 `--`；
- 回放期间 3 秒刷新不覆盖画面（`renderChart`/`renderKline` 有回放守卫），悬停十字光标关闭，切标的/周期/区间自动退出回放并恢复最新行情。

### 4. 告警与信号卡入场动效（A4）

- 新告警滑入（translateY + fade 450ms）+ 描边高亮衰减（1.8s，无填充模式，结束还原本色）；
- 信号卡在切换标的/周期/分析页签时错峰入场（每张延迟 45ms，`--fx-i` 由 JS 注入、950ms 后自动摘除类），3 秒例行重建不重播。

### 5. 骨架屏（A5）

- `index.html` 内置指数卡/汇总卡/自选表/信号卡的占位动画，覆盖 `snapshot.js`（约 3MB）解析期间的白屏；
- 数据就绪后由既有渲染链路替换：`ensureWatchRows` 显式移除骨架行，`ensureSummaryCards` 先清空骨架再建卡。

### 6. 信号卡存图（A6）

- 新增 `js/ui/share-card.js`：复用 `SignalEngine.compute` 的同一份计算结果，Canvas 2 倍采样合成 2160×1320 PNG（品牌行、价格、10 项指标网格、分析摘要、数据日期与免责声明页脚）；
- 入口在分析工作台右上角"存图"按钮，文件名 `股迹信号卡_代码_日期.png`，`toDataURL` 本地下载，不上传任何数据。

### 7. 无障碍与降级

- 系统"减少动态效果"（prefers-reduced-motion）时：CSS 动画由既有全局块归零，JS 补间由 `Motion.enabled()` 判定退化为直接赋值，回放功能不受影响；
- 回放条控件带 title 与 aria-label。

## 边界与如实说明

- **分时回放未做**：分时数据只来自腾讯实时接口，快照不含分钟数据。要做需先解决数据来源（会话内录制，或给 `build_snapshot.py` 加分钟采集），留给后续版本决策；
- **告警回放联动未做**：回放中不会触发历史告警（告警引擎按实时行情求值，直接复用会造成"伪告警"），列入后续候选；
- 自检保持 110 / 110：本版全部改动在 `js/ui/` 与样式层，未动 `js/core/` 纯函数，未凑用例数。
