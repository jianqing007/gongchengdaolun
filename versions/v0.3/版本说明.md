# v0.3 版本说明

- 日期：2026-10-31
- 状态：在 v0.25 的实时行情/持仓/分时/告警之上，补齐多周期 K 线、常用技术指标、追踪信号、组合风险和预测回测
- 运行：双击 `start.bat`，或 `python -m http.server 8000` 后打开 `index.html`
- 自检：`tests.html` 85 / 85 通过

## 一句话目标

让“看行情”变成“能复盘”：同一只股票可以切日/周/月 K，按需显示常用指标；分析工作台给出可解释的追踪信号、组合风险和诚实的样本外预测。

## 为什么这样改

- v0.25 只有分时图，看不到趋势和均线，无法回答“这只股票现在在什么位置”；
- 指标一次性全画会遮住 K 线，用户需要的是预设 + 多选 + 按周期记住选择；
- 只给“涨/跌”结论没有证据，必须同时给出指标口径、假设和样本外指标；
- 预测很可能跑不赢基线，但把失败结果藏起来才是真正的问题，所以页面保留原始数字。

## 本次实现

### 1. 数据层

- 快照从 2022 年扩展到 2015-01-01，采集到 2026-10-30；
- 茅台原始 2872 根日线，其中 372 根前复权价为负（2015—2016 年累计分红导致），读取时整根剔除，剩 2500 根；
- 周线 527 根、月线 124 根，由日线聚合：
  - 周线按 ISO 周（周一到周日），月线按自然月；
  - open 取第一根、close 取最后一根、high/low 取极值、volume 求和；
  - 最后一根未走完的周期标记 `partial`，图例显示“未走完”；
- 采集脚本增加保护：采集不完整时只写 `snapshot.partial.js`，不覆盖正在使用的 `snapshot.js`。

### 2. K 线图

- 四个页签：分时 / 日K / 周K / 月K；
- 指标：MA5/10/20/30/40/60/120/250、BOLL(20,2)、VOL、MACD(12,26,9)、KDJ(9,3,3)、RSI(6/12/24)；
- 预设三档：简洁（MA20/40 + VOL）、标准（MA5/10/20/40 + VOL/MACD）、完整（全部可用均线 + BOLL + VOL/MACD）；
- 均线多选、BOLL 开关、副图最多 2 个、月K默认对数坐标；
- 日K的 MA20/60/120/250 标注“月线/季线/半年线/年线”，周/月不加别名（避免把 20 周误读成一个月）；切换周期时指标面板同步刷新，周/月不提供 MA250；
- 十字光标显示 OHLC、涨跌幅、成交量、均线和副图值；
- 图例放在画布外，不遮挡 K 线；指标选择按周期保存到 `guji.chart.prefs.v1`。

### 3. 分析工作台

- **追踪信号**：9 张卡——趋势、MA40 偏离、MACD、KDJ、RSI、BOLL、20 日动量、20 日波动、距 20 日高点；摘要句由规则拼接；
- **观察池**：10 只股票固定权重打分，取前 5，页面写“观察”不写“推荐”；
- **组合风险**：第一大权重、等效持股数、20/60/250 日年化波动、60 日最大回撤、60 日 β、相关系数、有效样本；
- **预测与回测**：Holt 5 日预测 + 逻辑回归次日概率 + walk-forward 样本外指标。

### 4. 指标口径

| 指标 | 口径 |
| --- | --- |
| MA | 简单移动平均，样本不足返回 `null` |
| EMA | `α = 2/(n+1)`，首个有效值作种子 |
| MACD | `DIF = EMA12 − EMA26`，`DEA = EMA9(DIF)`，柱 `= 2 × (DIF − DEA)` |
| KDJ | `RSV = (C − L9)/(H9 − L9) × 100`，`K = 2/3·K_prev + 1/3·RSV`，`D = 2/3·D_prev + 1/3·K`，`J = 3K − 2D`，种子 50 |
| RSI | Wilder 平滑；全平盘 50，全上涨 100 |
| BOLL | MA20 ± 2 × 总体标准差 |
| 年化波动 | 日收益样本标准差 × √252 |
| 最大回撤 | 峰值到后续谷底的最大跌幅 |

## 实现中发现并修正的问题

1. `risk.js` 的 `var window = windowDays || 60` 遮蔽全局 `window`，导致 `window.PriceHistory` 取不到，组合风险和预测面板同时报 `dailyBars` 未定义；改名为 `windowSize`。
2. “250 日波动”实际只用了 60 个收益，因为公共日期被限成 61 天；改为 `max(windowSize + 1, 251)`，修复后与 Python 复算一致。
3. 茅台 2015—2016 年有 372 根前复权负值 bar；改为读取时剔除，并在界面显示“已剔除 N 根负值”。
4. 月K线性坐标会把早年压成一条线，且 padding 会产生负刻度；改为默认对数坐标、在对数空间做 padding。
5. 切换周期后指标面板不刷新：日K的 MA250 会留在周/月面板里，勾选后写进周线偏好；改为 `handlePeriodChange` 中重绘面板，并在 `sanitizePrefs` 里按周期限制均线上限（日 250，周/月 120）。同时给日K均线补中文别名，解决“只看到 MA250、不知道是年线”的问题。

## 已知问题

1. 预测模型很弱：命中率 51.3% 低于多数类基准 53.8%，AUC 0.489 接近随机，Holt MAE 也高于朴素基线；页面如实展示，不据此推荐；
2. 技术指标为自行实现，不保证与任何行情软件逐位一致；
3. 周/月聚合不处理法定节假日；
4. 组合风险假设权重不变、每日再平衡，未计现金、手续费、税费和停牌；
5. 减仓不计算已实现盈亏，也没有 FIFO 批次成本；
6. 只对茅台做了完整的预测演示，其他股票要等本人切换后复测；
7. 快照数据截至 2026-10-30，之后不会自动更新。
