# 股迹 v0.3 · 运行说明

> 版本：v0.3（2026-10-31）
> 定位：实时行情 + 持仓盈亏 + 分时 + 日/周/月 K 线 + 常用技术指标 + 追踪信号 + 组合风险 + 预测回测的本地看板。
> 数据来源：腾讯证券公开行情接口。仅供课程学习，不构成投资建议。

---

## 1. 运行环境

- Windows 10/11；
- Chrome 或 Edge（推荐最新版）；
- 实时行情、分时和历史日线需要联网；
- 可选：Python 3（只用于启动本地静态服务器，不需要安装任何第三方包）。

程序本身是纯静态网页，不需要 npm、不需要后端、不需要 API Key，也没有引入任何第三方图表库。

---

## 2. 启动方法

### 方法 A：双击 `start.bat`（推荐）

1. 双击 `start.bat`；
2. 会弹出一个“股迹本地服务器”命令行窗口，并自动打开浏览器；
3. 地址是 `http://localhost:8000/index.html`；
4. 关闭那个命令行窗口即停止本地服务器。

如果 8000 端口被占用，命令行窗口会提示错误。此时可以在项目目录手动执行：

```bat
python -m http.server 8080
```

然后浏览器打开 `http://localhost:8080/index.html`。

### 方法 B：直接双击 `index.html`

腾讯行情接口返回 `Access-Control-Allow-Origin: *`，所以从 `file://` 打开通常也能取到行情。部分浏览器对本地文件限制较严，如果行情不刷新，改用方法 A。

### 方法 C：手动启动

在项目目录执行：

```bat
python -m http.server 8000
```

浏览器打开 `http://localhost:8000/index.html`。

## 3. 页面操作

### 3.1 行情与持仓

1. **自选行情**：10 只股票每 3 秒批量刷新，显示最新价、涨跌幅、涨跌额、量比、换手率、最高/最低。刷新采用增量更新，只改变化的数字，不重建整张表。
2. **建仓**：右侧表单默认是“建仓”，选择一只尚未持有的股票，填股数和成本价，点“确认建仓”。股数必须是正整数，成本价必须大于 0；如果股票已持仓，会提示改用“加仓”或“修正”。
3. **加仓**：在“我的持仓”行点“加仓”，输入本次新增股数和本次成本价。系统按加权平均合并成本，不会生成第二行。例如 100 股 @1500 加 100 股 @1300，合并为 200 股 @1400。
4. **减仓**：在持仓行点“减仓”，输入减持股数；每股成本保持不变。减到 0 会弹窗确认并清仓；减仓不计算已实现盈亏。
5. **修正**：在持仓行点“修正”，直接修改这条持仓的股数和成本价，仅用于纠正录入错误，不按加仓/减仓计算。
6. **删除**：直接删除整条持仓；如果只是想卖出一部分，用“减仓”。
7. **合计**：总市值、总成本、浮动盈亏、今日盈亏、权重都会随行情刷新；金额以“分”为单位计算，避免浮点误差。

### 3.2 图表：分时 / 日K / 周K / 月K

8. **分时**：在股票下拉框切换标的，或用“腾讯分时”按钮回到分时。优先请求腾讯分时接口；接口不可用时，用本次页面打开后累积的 3 秒采样点兜底。快照模式下分时图暂停，避免混用不同交易日的价格。
9. **K 线周期**：图表上方有“分时 / 日K / 周K / 月K”四个页签。日线来自快照，周线和月线由日线聚合：
   - 周线按 ISO 周（周一到周日）分组，`open` 取第一根开盘、`close` 取最后一根收盘、`high/low` 取区间极值、`volume` 求和；
   - 月线按自然月分组，规则相同；
   - 最后一根尚未走完的周/月会标“未走完”，不冒充完整周期。
10. **指标面板**：点“指标”展开。预设三档：
    - 简洁：MA20、MA40 + 成交量；
    - 标准：MA5/10/20/40 + 成交量 + MACD；
    - 完整：当前周期全部可用均线 + BOLL + 成交量 + MACD。
11. **自定义指标**：
    - 均线可多选：日K提供 MA5/10/20/30/40/60/120/250，周/月提供到 MA120；样本不足的均线自动禁用，不会画出半截线；
    - BOLL(20,2) 可单独开关；
    - 副图最多同时选 2 个：成交量、MACD、KDJ、RSI；
    - 月K默认使用对数坐标（16 元到 2385 元的跨度在线性坐标下会把早年压成一条线），可手动关闭；
    - 指标选择按周期分别保存在 `localStorage` 的 `guji.chart.prefs.v1`。
12. **十字光标**：鼠标移到 K 线上显示该根的开高低收、涨跌幅、成交量、均线和副图指标值；移动端用手指按住查看。

### 3.3 分析工作台

13. **追踪信号**：对当前选中股票，按日/周/月线计算 9 张规则卡：
    - 均线排列（MA5/10/20/40/60 多头/空头/震荡）；
    - 收盘价相对 MA40 的偏离；
    - MACD 金叉/死叉/多头/空头与红绿柱变化；
    - KDJ 超买/超卖/偏多/偏空；
    - RSI6/12/24 超买/超卖/中性；
    - BOLL 上轨/中轨/下轨位置与带宽；
    - 20 日动量、20 日年化波动、距 20 日高/低点。
    摘要句由这些规则拼接，明确标注“规则生成，仅供课程学习”。
14. **观察池**：对 10 只自选股用固定权重打分（20 日动量 18、趋势 15、MACD 8、量能 5、低波动 -8），取前 5 名。页面写“观察池”，不写“推荐”。
15. **组合风险**：按当前持仓市值权重计算：
    - 第一大权重、等效持股数（1/HHI）；
    - 20/60/250 日年化波动；
    - 60 日最大回撤；
    - 相对沪深 300 的 60 日 β 与相关系数；
    - 有效样本天数。
    假设：权重不变、每日再平衡、无现金/手续费、前复权收盘价、252 个交易日/年。单票权重超过 30%、β 高于 1.2 会标黄。
16. **预测与回测**：点“运行回测”后：
    - Holt 双指数平滑（在对数收盘价上）给出未来 5 个交易日的点预测和 80% 区间；
    - 逻辑回归用 7 个特征给出“次日上涨概率”；
    - walk-forward 按时间顺序滚动训练/预测，不使用未来数据；
    - 同时显示样本外方向命中率、基准命中率、AUC、精确率/召回率、Holt MAE 与朴素基线。
    模型结果只使用历史日线，页面明确写“不构成投资建议”；跑输基准时如实显示，不粉饰。

### 3.4 告警、快照与存储

17. **盘中告警**：实时行情触发三类基础规则——
    - 涨跌幅绝对值达到 3%；
    - 量比达到 2；
    - 价格上穿/下破 20 日均线，或创 20 日新高/新低。

    同一股票 + 同一规则 30 分钟内只提醒一次；告警流最多保留 50 条。快照/离线状态不产生新告警。
18. **快照兜底**：连续 3 次行情请求失败后自动切换内置的前复权日线快照，顶部显示“快照模式”和快照时间；之后按 3/6/12/30 秒退避重试。
19. **本地持仓恢复**：持仓保存在 `localStorage` 的 `guji.holdings.v2`。如果该键被手动改成非法 JSON，页面会：
    - 把原文备份到 `guji.holdings.corrupt.<时间戳>`；
    - 恢复示例持仓；
    - 显示黄色提示，说明备份键名；
    - 旧版 `guji.holdings.v1` 数组会自动迁移。
20. **清空/示例**：右上角“载入示例”会替换当前持仓；“清空”会删除全部持仓。
21. **自检页**：打开 `tests.html`，应显示“85 / 85 通过”。这是纯函数断言，不发起行情请求。

- 自检从 47 条扩展到 85 条。

### 指标口径

| 指标 | 口径 |
| --- | --- |
| MA | 简单移动平均，样本不足返回 `null`，不拿 0 顶替 |
| EMA | `α = 2/(n+1)`，第一个有效值作为种子 |
| MACD | `DIF = EMA12 − EMA26`，`DEA = EMA9(DIF)`，柱 `= 2 × (DIF − DEA)` |
| KDJ | `RSV = (C − L9)/(H9 − L9) × 100`，`K = 2/3·K_prev + 1/3·RSV`，`D = 2/3·D_prev + 1/3·K`，`J = 3K − 2D`，种子 50 |
| RSI | Wilder 平滑，6/12/24；全平盘记 50，全上涨记 100 |
| BOLL | MA20 ± 2 × 总体标准差；标准差为 0 时三轨重合 |
| 年化波动 | 日收益样本标准差 × √252 |
| 最大回撤 | 区间内峰值到后续谷底的最大跌幅 |

### 边界与已知问题

- 技术指标按常见公式自行实现，不保证与任何行情软件的数值逐位一致（种子、复权、停牌处理可能不同）；
- 周线按 ISO 周、月线按自然月聚合，不处理法定节假日；
- 预测模型很弱：茅台当前样本外方向命中率 51.3%，低于“总是猜多数类”的 53.8% 基准，AUC 0.489 接近随机；页面如实展示，不据此给出买卖建议；
- Holt 5 日 MAE 48.17，高于朴素基线 45.02，说明该窗口内平滑模型没有跑赢“直接用最后一天”；
- 组合风险假设权重不变、每日再平衡，未计现金、手续费、税费和停牌；
- 减仓不计算已实现盈亏、手续费和税费，也没有按批次（FIFO）记成本；
- 告警是规则引擎，不是机器学习；告警不写入 localStorage，刷新页面后清空；
- 快照数据截至采集日（见 `js/data/snapshot.js` 的 `meta.fetchedAt`），之后不会自动更新；
- 页面关闭后不再盯盘，不是 7×24 服务。

## 5. 数据来源与合规

- 实时报价、分时、历史日线均来自腾讯证券公开接口；
- 历史数据为前复权日线，成交量单位为手；
- 快照覆盖 2015-01-01 至采集日，10 只股票 + 2 个指数；
- 前复权价可能出现 0 或负值（累计分红导致），这些 bar 在读取时被剔除，并在界面标注数量；
- 程序不接入券商、不执行交易、不上传持仓，不包含账号密码；
- 页面固定显示“仅供课程学习，不构成投资建议”。

## 8. 常见问题

**K 线区域空白**
- 确认已点“日K/周K/月K”，分时页签下不显示 K 线；
- 打开 Console 看是否有脚本报错；
- 快照文件很大（约 1.6 MB），首次加载会比 v0.25 慢一点。

**月K的早年价格很低甚至为负**
- 腾讯前复权价在 2015—2016 年可能出现负值；项目已剔除这些 bar，并在图例旁提示“已剔除 N 根负值”；
- 月K默认对数坐标，是为了让 16 元到 2385 元的跨度都能看清，不是数据错误。

**预测按钮提示“至少需要 250 根日线”**
- 该股票快照样本不足，无法做 walk-forward；换一只上市更早的股票再试。

**预测命中率低于基准**
- 这是真实结果，不是显示错误。模型只用了 7 个价量特征，样本外跑不赢“多数类”基准很正常；
- 页面保留原始数字和假设，不把预测包装成投资建议。

**行情一直显示“--”**
- 检查网络；打开开发者工具 Console/Network 看请求是否失败；
- 腾讯接口可能临时限制访问，等一会儿点“刷新”，或直接看快照模式。

**持仓刷新后没了**
- 检查浏览器是否禁用了 localStorage；
- 换浏览器/清缓存会丢失，本项目没有云端同步；
- 如果看到“本地持仓数据损坏”，按提示到 `guji.holdings.corrupt.*` 备份键找原文。

**页面打开是空白**
- 确认脚本没有被浏览器插件拦截；
- 用 `start.bat` 的 localhost 方式打开；
- 打开 Console 看是否有报错，并截图记录。

**端口被占用**
- 手动执行 `python -m http.server 8080`，改用 8080。

## 9. 重新采集快照

```bat
python tools/build_snapshot.py
```

脚本会从腾讯证券接口按结束日期向前翻页，采集 2015-01-01 至今的日线，写入 `js/data/snapshot.js`。需要系统 `curl`（Windows 10/11 自带）。如果采集不完整，脚本只写 `snapshot.partial.js`，不会覆盖正在使用的 `snapshot.js`。采集完成后刷新页面即可使用新快照。
