## 吉祥物：素材与实现（如实说明）

- **素材来源**：`assets/涨涨涨_Q弹.svg` 由使用者本人制作提供（位图贴纸嵌入 SVG，自带 idle 呼吸与 bounce Q 弹两组关键帧动画定义）。本轮曾先由 AI 手绘矢量建模迭代三轮，使用者不满意后改为直接采用其自制素材，此前的手绘版本未保留。
- **构建**（`tools/build_mascot_art.py`，常驻工具，可复现）：
  1. 内嵌位图的纯白背景转透明——从画布四边泛洪填充，仅"与边框连通"的近白像素透明，角色内部被描边包住的白色（思考泡、蕾丝褶边、白裙）不受影响；
  2. 剥离素材内嵌 `<script>`（innerHTML 注入本就不会执行）与根节点 512px 固定尺寸/白底内联样式；
  3. 导出为 `js/ui/mascot-art.js` 的 `window.MASCOT_SVG` 字符串，页面加载时由吉祥物脚本注入 DOM。
- **交互**（`js/ui/mascot.js`）：点击触发素材自带 bounce 动画并随机冒语录（6 条加权随机、不连续重复，"涨涨涨！📈"权重 2）；实时行情触发上涨类告警时欢呼"涨啦！🎉"（`app.js` 一行钩子，复用既有告警管线）；气泡弹入/停留/淡出；真实 `<button>` + aria-label，键盘可操作。
- **修复素材原有小缺陷**：素材 CSS 规则 `#wrap.bounce` 优先级高于 `#wrap`，Q 弹播完若不摘类，呼吸动画会被永久顶掉（素材原内嵌脚本同样存在此问题）——现 bounce 结束即摘类，呼吸自然回归。
- **边界**：吉祥物纯装饰，不参与任何数据与功能逻辑；语录池为固定文案，不含任何行情数据。

## 对比度修复（style.css 原位改，不动全局 `--muted`）

| 控件 | 改法 | 实测对比度 |
|---|---|---|
| `.btn-ghost`（命令面板/刷新等幽灵按钮） | 边框/文字/底色提亮，hover 再亮一档 | ≈10.2:1 |
| `.chart-tab` / `.analysis-tab` 激活态 | 蓝底白字小胶囊 + 内描边 | ≈12.3:1 |
| `.indicator-chip` / `.indicator-check` | 边框与字色提亮，激活态高亮 | ≈9.8:1 |
| `.chart-select` | 边框提亮 | — |
| 全部按钮 | 新增 `:active` 按压下沉反馈 | — |

以上文字对比度均 ≥ WCAG AA 的 4.5:1。
