# 股迹 · 纯前端股票追踪与 AI 分析助手

零依赖的纯静态网页：HTML5 + CSS3 + 原生 ES2017 JavaScript，图表用 Canvas 手绘，不引入任何第三方库、不需要 npm、不需要后端、不需要 API Key。行情来自腾讯证券公开接口，持仓只保存在本机浏览器（localStorage），不连接券商、不执行交易、不上传任何数据。

## 怎么打开

**方式一：在线地址（推荐，零安装）**

直接访问 GitHub Pages：<https://PLACEHOLDER.github.io/REPONAME/>

**方式二：下载 ZIP，双击即开**

1. 点本页绿色 **Code** 按钮 → **Download ZIP**，解压；
2. 双击 `index.html` 即可在浏览器中打开（行情接口允许跨域，`file://` 直开可用；个别浏览器限制较严时改用方式三）。

**方式三：ZIP + start.bat（本地服务器）**

解压后双击 `start.bat`，会先自动增量更新快照（联网时约 10–30 秒；断网自动跳过），再启动本地服务器并打开浏览器（需要 Python 3，无需安装任何第三方包；没有 Python 时按方式二）。

## 自检

打开 `tests.html`，应显示 **110 / 110 通过**——纯函数断言，覆盖持仓、存储、指标、信号、告警、总览、风险与预测，不发起行情请求。

## 功能一览

- 实时行情（3 秒刷新）与持仓管理：建仓 / 加仓 / 减仓 / 修正，金额按分计算；
- 分时图与日 / 周 / 月 K 线：MA / MACD / KDJ / RSI / BOLL / 成交量，三档预设；
- 日K历史回放：逐根重放快照历史，指标按"当日为止"重算，1×–8× 变速；
- 信号卡存图：一键把当前标的的追踪信号合成为 PNG 图片；
- 规则化告警：涨跌幅 ±3%、量比 ≥2、20 日均线与新高新低、MACD 金叉死叉（250 根回看、临界标注）；
- 追踪信号 10 张卡、池子总览（当日涨跌排序 + 相对强度）、创业板指 / 科创 50 指数闸门；
- 组合风险（波动、回撤、β）与带样本外评估的预测模块（walk-forward，跑输基准也如实展示）。

完整说明见 [`运行说明.md`](运行说明.md)。

## 目录结构

- `index.html` / `tests.html` — 主页面与自检页；
- `js/` — 全部源码（`data/` 快照与清单、`core/` 纯函数、`ui/` 渲染与图表）；
- `tools/` — `build_universe.py`（清单校验）、`build_snapshot.py`（日线采集与增量更新）；
- `versions/` — v0.1 → v0.4 五轮迭代的完整归档，`versions/v0.4/版本说明.md` 记录每轮改动。
