# v0.5.1 版本说明

- 日期：2026-11-05
- 状态：v0.5 补丁（启动器自动更新快照 + 自检用例修正）；功能、指标口径、告警规则、UI 均未改动
- 自检：`tests.html` 110 / 110 通过（用例数量未变，6 条用例的断言方式修正）
- 数据：快照由 2026-10-30 例行更新到 2026-11-04（26 个标的全部覆盖）

## 一句话目标

把"更新快照"从手动敲命令变成双击 `start.bat` 的自带动作，并修复例行数据更新暴露出的自检用例对快照时点的硬编码依赖。

## 为什么这样改

- 用户看到"快照已过期 N 个交易日"横幅后仍需手动运行 `--update`；启动器本来就要起服务器，顺手把增量更新做在启动流程里；
- 例行数据更新（10-30 → 11-04）让自检一度 104/110：6 条用例把"数据截至日期 / 具体涨跌幅 / 金叉名单"钉死在 2026-10-30。这些是测试缺陷（绑定会移动的市场数据），不是功能退化。

## 本次实现

### 1. start.bat 启动自动更新快照

- 启动器在起服务器之前先运行 `python tools/build_snapshot.py --update`（增量，带 10 天重叠区复权校验），成功后才启动本地服务器并打开浏览器；
- 更新失败（断网、接口临时不可用）**不阻断启动**：打印提示后继续用现有快照，页面横幅会如实显示数据日期；
- Python 缺失时的降级路径不变（提示直接双击 index.html）；
- exit code 由脚本 `raise SystemExit(main())` 正常传播，bat 用 `if errorlevel 1` 判断。

### 2. 过期横幅与 tooltip 文案

- `js/ui/app.js` 两处字符串：横幅提示改为"双击 start.bat 可自动更新（增量，约 10–30 秒），或手动运行 …"；数据截至徽标的 tooltip 同步。

## 边界与如实说明

- `file://` 直开（方式 B）与未来的 GitHub Pages 在线版**不会**自动更新快照——浏览器不能写本地文件，快照是打包时点的静态文件；在线版"前端拉增量合并显示"列为 v0.6 候选；
- 盘中运行 `--update` 会拿到未收盘的当日柱（close = 当时最新价）；下一次收盘后的更新会按日期覆盖为最终收盘值（`merge_bars` 新数据覆盖旧数据）。课程口径建议收盘后再更新；
- 现网快照含 2026-11-04 收盘最终值（凌晨复跑已覆盖此前可能存在的盘中柱）；
- 快照模式兜底、指标口径、告警规则均未改动。
