# 股迹 v0.1 · 运行说明

> 版本：v0.1（2026-10-30）
> 定位：实时行情 + 持仓盈亏的本地看板，是后续 AI 盯盘/分析/预测/观察池的数据底座。
> 数据来源：腾讯证券公开行情接口。仅供课程学习，不构成投资建议。

---

## 1. 运行环境

- Windows 10/11；
- Chrome 或 Edge（推荐最新版）；
- 实时行情需要联网；
- 可选：Python 3（只用于启动本地静态服务器，不需要安装任何第三方包）。

程序本身是纯静态网页，不需要 npm、不需要后端、不需要 API Key。

---

## 2. 启动方法

### 方法 A：双击 `start.bat`（推荐）

1. 双击 `start.bat`；
2. 会弹出一个“股迹本地服务器”命令行窗口，并自动打开浏览器；
3. 地址是 `http://localhost:8000/index.html`；
4. 关闭那个命令行窗口即停止本地服务器。

如果 8000 端口被占用，命令行窗口会提示错误。此时可以在项目目录手动执行：

```bat
python -m http.server 8080
```

然后浏览器打开 `http://localhost:8080/index.html`。

### 方法 B：直接双击 `index.html`

腾讯行情接口返回 `Access-Control-Allow-Origin: *`，所以从 `file://` 打开也能取到行情。部分浏览器对本地文件限制较严，如果行情不刷新，改用方法 A。

### 方法 C：手动启动

在项目目录执行：

```bat
python -m http.server 8000
```

浏览器打开 `http://localhost:8000/index.html`。

## 3. 页面操作

1. **自选行情**：10 只股票每 3 秒批量刷新，显示最新价、涨跌幅、涨跌额、量比、换手率、最高/最低。
2. **添加持仓**：在右侧表单选择股票、填股数和成本价，点“添加持仓”。股数必须是正整数，成本价必须大于 0；同一只股票不能重复添加。
3. **编辑/删除**：在“我的持仓”表格右侧点“编辑”或“删除”。编辑时表单会切换到“保存修改”，可点“取消编辑”退出。
4. **合计**：总市值、总成本、浮动盈亏、今日盈亏、权重都会随行情刷新；金额以“分”为单位计算，避免浮点误差。
5. **快照兜底**：连续 3 次行情请求失败时，自动切换到内置的 2022—2026 前复权日线快照，顶部显示“快照模式”和快照时间。
6. **断网测试**：打开浏览器开发者工具 → Network → 勾选 Offline，等下一次刷新；页面应显示快照或“更新失败”，不应崩溃。
7. **清空/示例**：右上角“载入示例”会替换当前持仓；“清空”会删除全部持仓。持仓保存在浏览器 localStorage（键名 `guji.holdings.v1`），不上传。
8. **自检页**：打开 `tests.html`，应显示“全部通过”。这是纯函数断言，不发起行情请求。

## 4. v0.1 已知边界

- 只有行情和持仓盈亏，没有分时图、K 线、告警、AI 分析/预测/观察池——这些在 v0.2/v0.3/v1.0 实现；
- 行情是约 3 秒快照，不是逐笔成交；接口可能延迟或中断；
- 交易状态只按北京时间判断周一至周五的 9:30—11:30、13:00—15:00，不处理法定节假日；
- 快照数据截至采集日（见 `js/data/snapshot.js` 的 `meta.fetchedAt`），之后不会自动更新；重新采集执行 `python tools/build_snapshot.py`；
- 持仓保存在本机浏览器，换浏览器或清缓存会丢失；
- 页面关闭后不再盯盘，不是 7×24 服务。

---

## 5. 数据来源与合规

- 实时报价、分时、历史日线均来自腾讯证券公开接口；
- 历史数据为前复权日线，成交量单位为手；
- 程序不接入券商、不执行交易、不上传持仓，不包含账号密码；
- 页面固定显示“仅供课程学习，不构成投资建议”。

## 8. 常见问题

**行情一直显示“--”**
- 检查网络；打开开发者工具 Console/Network 看请求是否失败；
- 腾讯接口可能临时限制访问，等一会儿点“刷新”，或直接看快照模式；
- 确认系统时间正确（交易状态按本机时间换算北京时间）。

**页面打开是空白**
- 确认脚本没有被浏览器插件拦截；
- 用 `start.bat` 的 localhost 方式打开；
- 打开 Console 看是否有报错，并截图记录。

**持仓刷新后没了**
- 检查浏览器是否禁用了 localStorage；
- 换浏览器/清缓存会丢失，v0.1 没有云端同步。

**端口被占用**
- 手动执行 `python -m http.server 8080`，改用 8080。

## 9. 重新采集快照

```bat
python tools/build_snapshot.py
```

脚本会从腾讯证券接口按结束日期向前翻页，采集 2022-01-01 至今的日线，写入 `js/data/snapshot.js`。需要系统 `curl`（Windows 10/11 自带）。采集完成后刷新页面即可使用新快照。
