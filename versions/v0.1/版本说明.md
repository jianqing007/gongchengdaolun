# v0.1 版本说明

- 日期：2026-10-30
- 状态：可运行的第一版，作为后续迭代的基线
- 运行：双击 `start.bat`，或直接打开 `index.html`

## 已实现

- 10 只 A 股 + 2 个指数的实时报价（腾讯公开接口，3 秒批量刷新）；
- 持仓添加 / 编辑 / 删除，localStorage 持久化；
- 市值、成本、浮动盈亏、日盈亏、盈亏比例、权重、合计；
- 金额以“分”为整数计算，避免浮点累计误差；
- 连续失败切快照模式（内置 2022-01-04 至 2026-10-29 前复权日线）；
- 纯函数自检页 `tests.html`，23 条断言全部通过；
- 响应式布局（桌面 / 平板 / 手机）。

## 本版发现并修正的问题

1. 行情计数把指数算进“10 只标的”，显示 12/12 → 改为只统计股票；
2. 部分行情缺失时今日盈亏显示部分合计 → 改为“--”；
3. 首次打开成本价为空 → 按当前股票最新价预填；
4. 手机端表单排在行情表前面 → 调整顺序；
5. 快照时间显示采集时间而非行情截止时间 → 改为最后一根 K 线 15:00，并区分“快照日盈亏”。

## 已知问题（第一轮迭代输入）

1. 每 3 秒整表 `innerHTML` 重绘：自动化点击会被重绘打断，真人也可能丢失点击、打断文本选择；
2. 表单只有字段级错误，没有错误汇总、保存成功反馈；
3. localStorage 没有版本号和损坏备份，非法 JSON 时直接回退示例；
4. 没有分时图、K 线、告警、AI 分析/预测/观察池；
5. 交易状态不处理法定节假日；
6. 快照模式与实时模式的文案还可以统一。

## 第一轮迭代目标（v0.2）

一句话：**让刷新不打断操作、让错误可恢复、让盘中信息看得见。**

- 行情表/持仓表改为增量更新（只更新变化的单元格），不再整表重绘；
- localStorage 加版本号、结构校验、损坏备份与提示；
- 表单加错误汇总、保存成功提示、空状态优化；
- 加当日分时图（Canvas）与基础告警规则（涨跌幅、量比、均线突破、新高新低）；
- 告警去重/冷却，页面隐藏暂停刷新；
- 补 T1—T8 手动测试记录与交易时段截图。
