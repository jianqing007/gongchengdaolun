# v0.8 版本说明

- 日期：2026-11-25
- 状态：在 v0.7 之上新增"日线页面内续读"；数据口径、指标算法、告警规则、自检用例均未改动
- 运行：双击 `start.bat`（启动时自动增量更新快照），或 `python -m http.server 8000` 后打开 `index.html`
- 自检：`tests.html` 110 / 110 通过（续读只影响页面内存与渲染层，未新增/修改纯函数用例）；另有 Playwright 冒烟 22 项全过（三种续读场景 + 真实环境 + v0.7 回归）
- 数据：26 个标的；快照文件不再刷新时，页面也能把日线"续"到最新交易日

## 一句话目标

解决"数据不会自动更新、要靠 start.bat"的痛点：打开页面的瞬间，日线自动续读到最新交易日——不点任何按钮、不装任何东西，GitHub Pages 在线版同样生效。

## 为什么此前要手动更新（如实说明）

快照 `js/data/snapshot.js` 是打包时点的静态文件，浏览器安全沙箱不允许网页改写本地文件，所以更新只能靠页面之外的程序（`build_snapshot.py`，start.bat 启动时自动执行）。实时行情/分时一直是可以自动刷新的；本次补的是"日线历史"这一块。

## 可行性前提（动手前已验证）

腾讯日线接口 `web.ifzq.gtimg.cn/appstock/app/fqkline/get` 对浏览器请求返回 `Access-Control-Allow-Origin: *`，与分时接口同等待遇——页面可以自己拉日线。这也是在线版的唯一日线保鲜途径（在线版没有 Python）。

## 实现

### 1. 拉取与校验（`js/data/extend.js`，新增）

- 页面加载完成后异步执行，不阻塞首屏；并发 4、单标的失败不影响整体、三域名容灾（与 `build_snapshot.py` 同款域名序列）；
- **前复权校验口径与 `build_snapshot.py` 逐条一致**：股票用 qfq、ETF/指数不复权；重叠窗取快照末日前 10 个日历日；容差 max(0.011, |收盘|×1e-4)；任一标的检测到因子变化 → **整体停用续读**并在顶部提示运行 start.bat（内存里无法像采集脚本那样按标的重建全量，如实降级比带病合并诚实）；
- 合并只追加"晚于该标的快照末日"的行（各标的末日可能不同，分别补缺口），按日期升序去重。

### 2. 数据层扩展（`js/data/history.js`）

- 新增 `applyExtension(ext)`：把增量行挂进 `PriceHistory`，`dailyBars/barsFor/lastDate` 等既有入口直接合并渲染；缓存键追加续读戳，应用后一次性失效；
- 无续读时（扩展为空）全部行为与 v0.7 逐字节一致——这就是自检 110/110 不变的原因。

### 3. 界面（`js/ui/app.js`）

- 顶部徽标：续读成功显示"数据截至 X（快照 Y + 页面续读）"，悬停有口径说明；过期横幅改按"续读后的有效日期"判断；
- 复权变化时无条件显示提示横幅（与快照新旧无关）；
- 续读成功且新增后局部重绘图表/信号/总览；日K回放进行中不重绘（不打断回放）；
- 右上"刷新"按钮顺带重新续读。

## 冒烟测试（Playwright 路由拦截，22 项全过）

- 场景 1 正常续读：夹具从磁盘快照生成（重叠区收盘价逐分一致），+2 根/标的 → applied=52、图表 lastDate 前移、徽标文案正确；
- 场景 2 复权因子变化：夹具篡改重叠区收盘 ×1.1 → 26 标的全部识别为 mismatch、**零合并**、横幅提示 start.bat；
- 场景 3 接口全挂：状态 failed、徽标保持快照日期、无 JS 错误；
- 真实环境：实际拉取到 15 根增量（快照里 14 个标的停在 11-24，页面自动补齐）；
- 回归：吉祥物、建仓+撤销、Ctrl+K 面板、K线滚轮缩放、自检 110/110。

## 过程中如实记录的问题与修复

1. **初版 `fetchAll` 竞态**：并发池在"最后一个请求发出"时就 resolve，慢链路的响应还没写回 results，26 个标的固定丢 3 个——冒烟抓出后改为"完成计数"语义（全部完成才 resolve）；
2. **腾讯 CDN 偶发不发 CORS 头**：浏览器侧表现为 CORS 拦截，靠三域名重试兜底（真实环境两次被拦均由备用域名救回）；CORS 失败属预期网络噪音，冒烟脚本不计为 JS 错误。

## 边界

- 续读只存在于页面内存：刷新页面重新拉取，不写快照文件、不进 localStorage；
- 复权因子变化时无自动修复（start.bat 重新生成快照是唯一正解），提示明确；
- 快照末日之后没有新交易日时（如收盘后当天），续读结果为空，徽标保持原样。
